# Rob McGuire — LCARS Resume

A single-page, LCARS-styled resume website. Static HTML/CSS/JS, no build step.
Built on the [TheLCARS.com](https://www.thelcars.com) template kit.

## Files

- `index.html` — the site. All resume content lives in the `<main>` element.
- `assets/` — theme stylesheets, Antonio fonts, and `lcars.js` (scroll-to-top, accordion).
- `LCARS/` — the original, untouched TheLCARS.com template kit, kept as reference.
- `RobM_Resume-March2024.docx` — source resume (not published as a download).
- `.nojekyll` — tells GitHub Pages to serve `assets/` verbatim.

## Swapping the theme (~every 6 months)

The active palette is set by **one line** near the top of `index.html`:

```html
<link rel="stylesheet" type="text/css" href="assets/classic.css">
```

Change `classic.css` to any of the bundled themes:

- `classic.css` — orange/gold (current)
- `nemesis-blue.css` — blue/steel
- `lower-decks.css` — bright animated-series palette
- `lower-decks-padd.css` — compact PADD variant

The Classic and Nemesis-Blue themes share the same Standard HTML scaffold, so swapping is
just the one line. The Lower-Decks themes use a slightly different wrapper; if moving to one
of those, copy the wrapper markup from the matching file in `LCARS/`.

## Updating content

Edit the `<main>` block in `index.html`. Section headings use
`<div class="lcars-text-bar"><h2>…</h2></div>`; multi-column lists use
`<div class="flexbox"><div class="col">…</div></div>`; role date lines use
`<p class="postmeta font-gold">`.

The email address is assembled in JavaScript at the bottom of the page so the plain address
does not appear in the page source (reduces scraping). The phone number is intentionally
omitted from this public page.

The Contact section uses LCARS pill buttons (`.pillbox`) for Email, LinkedIn, and a
Download Resume link. The downloadable `RobM_Resume.pdf` is a clean, recruiter-friendly
document (no phone number) generated by `build_resume_pdf.py`:

```sh
python3 -m pip install fpdf2   # one-time
python3 build_resume_pdf.py    # regenerates RobM_Resume.pdf
```

Core Competencies use a three-column grid (`.comp-cols`, defined in the `<style>` block in
`index.html`) that collapses to two columns, then one, on narrower screens.

## Local preview

```sh
python3 -m http.server
```

Then open <http://localhost:8000/>.

## Hosting (GitHub Pages)

Static, HTTPS, free. Push to a public repo, then **Settings → Pages → Source = `main` / root**.
The site serves at `https://<username>.github.io/<repo>/`.
